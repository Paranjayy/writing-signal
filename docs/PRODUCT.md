# Product: Writing Signal

## Reality snapshot

- **Primary user:** a keyboard-heavy macOS/Raycast user who wants a truthful view of writing effort.
- **Outcome:** understand when time disappears into writing, creating, focus, or consuming—without surrendering their text to a tracker.
- **Stage:** private prototype.
- **Primary platform:** macOS/Raycast.
- **Core constraint:** private material must never be collected implicitly.

## Product soul

Writing Signal is calm, private, and inspectable. It refuses to be a keylogger, a productivity guilt machine, or a cloud text archive.

## First-slice success criteria

1. A user can start and stop an activity session with a deliberate mode.
2. A user can capture selected text and see aggregate word/token statistics.
3. A user can inspect/clear the current clipboard without its contents being retained.
4. The data model can later accept events from a user-consented native client and an end-to-end encrypted sync vault.
